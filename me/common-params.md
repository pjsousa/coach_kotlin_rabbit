# Common Interview Preparation Parameters

## Candidate

- Current role: Lead Backend Engineer
- Target role: Product Engineer
- Experience level: Lead
- Resume: Not provided; profile is based on self-reported experience

## Preparation Window

- Preparation days: 30
- Preparation hours per day: 2
- Total preparation hours: 60

## Target Stack

- Primary language: Kotlin
- Kotlin framing: Kotlin for an experienced Java backend engineer
- Messaging: RabbitMQ
- Persistence: PostgreSQL
- Application framework: Spring Boot
- API style: REST, with SSE as an advanced patient-status capability
- Local infrastructure: Docker Compose
- Existing experience to leverage: Java, Python, Spring, C#, SQL Server, MongoDB, GCP, Kafka Streams, Google Pub/Sub

## Target Context

- Domain: Pharmacy and healthcare fulfillment
- Challenge: `Product Engineer_ Tech Challenge.md`
- Core workflow: prescription submission, inventory verification, pharmacist approval, packaging, fulfillment, patient status visibility
- Assessment constraint: approximately 2-5 hours for the submitted implementation
- Assessment areas: user experience, simplicity, system design, and failure handling

## Explicit Learning Goals

- Become productive in Kotlin from a senior Java baseline.
- Deepen RabbitMQ knowledge beyond tutorial-level usage.
- Transfer SQL Server transaction and concurrency knowledge to PostgreSQL.
- Design and implement reliable asynchronous workflows with outbox, retries, DLQ, and idempotent consumers.
- Build and prove patient status updates with SSE, ordering, reconnect, and isolation between patients.
- Explain design and tradeoffs in an offline code review, live walkthrough, system-design discussion, and behavioral interview.
