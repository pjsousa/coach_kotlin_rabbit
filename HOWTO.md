# Elite Tech Prep

A progressive, LLM-driven pipeline that transforms your CV and target job description into a structured interview preparation workflow. 
Each prompt builds on the last.
Designed for engineers who want a rigorous, personalized elite prep system rather than scattered online resources.

## Recommended Flow

Progress through the elite*.prompt.files in the order above.
Feel free to cast off on your own at any step.

Kick each of the main prompts in a new llm session.
- elite-coach-planner.prompt.md
    - this will give you `coach-assessment.md` which will tell you what to focus on
    - go and study that
    - OR spin up `elite-blog-author.prompt.md` and point it to it
- elite-blog-author.prompt.md
    - `elite-blog-author.prompt.md` will give you a pan for as many "blog post series" as you need to prepare
    - that plan will show up in `blog-plan.md`
    - either steer the `elite-blog-author` to delegate the actual writting of the posts (see steering snippets below)
    - OR manually kick off `elite-blog-writer.prompt.md` with a blog title from the `blog-plan.md`
    - if you want to have some sort of directed hands-on experience, proceed to `elite-exercise-architect.md`
- elite-exercise-architect.md
    - The `elite-exercise-architect.md` will look at all your artifacts and plan a hands-on progressive exercise
    - It will not write the exercises themselves
    - It will leave that plan in a new fully cusomized `exercise-writer-prompt.md`
    - you can either steer the project builder to run it
    - OR start a new session with it yourselve
    - after `exercise-writer-prompt.md` is finished, you will have a new `showcase_projects` with a set of exercices to run through
    - tackle the exercices on your own
    - OR if you fill stuck, jump into the exercice and kick-off `elite-live-coding-coach.prompt.md` as you need
- elite-live-coding-coach.prompt.md
    - assumes you have some showcase_projects to go through
    - looks or asks for which exercice you are working on
    - guides you through instead of just giving you the solution
- elite-interviewer.prompt.md
    - anytime you feel ready, sping up the `elite-interviewer.prompt.md` and let it roast and grill you
    - if you feel in dire need of help, emotional support or just want to watch what it looks like to nail every single answer, brin `elite-candidate.prompt.md` into another session and let them go at it.


## Usual file structure

```
.
├── 00.elite-tech-prep.md                         ← this file — index & navigation
│
├── me/                                            ← YOU are the author of these files (place them here before starting)
│   ├── CV.md                                      ← your curriculum vitae
│   ├── jobdescription.md                          ← the job description you're targeting
│   └── common-params.md                           ← unified calibration params (can be generated by `[1]`)
│
├── artifacts/                                     ← prompts below will GENERATE these as you progress
│   ├── coach-assessment.md                        ← Result from `[1]`. is the gap analysis & study plan report
│   ├── blog-plan.md                               ← Resould from `[2]` output: blog series curriculum
│   ├── exercise-writer-prompt.md                  ← `[3]` output: self-contained exercise writer
│   └── exercise-writer-prompt-progression2.md     ← `[3]` output: second progression (if needed)
│
├── posts/                                         ← `[2]` produces these (one folder per series)
│   ├── series-`<N>`-*
│   └── (...)
│
├── showcase_projects/                             ← `[3]` produces these (one folder per progression)
│   └── (...)
│
├── elite-coach-planner.prompt.md                  ← Step `[1]`: gap analysis & study plan
├── elite-blog-author.prompt.md                    ← Step `[2]`: blog series curriculum design
├── elite-blog-writer.prompt.md                    ← Step `[2b]`: writes one blog post per trigger
├── elite-exercise-architect.md                    ← Step `[3]`: generates exercise-writer prompts
├── elite-live-coding-coach.prompt.md              ← Step `[4]`: Live coach for the showcase_projects
├── elite-interviewer.prompt.md                    ← Step `[5a]`: drives mock interviews
└── elite-candidate.prompt.md                      ← Step `[5b]`: helps with mock interviews
```

### Steering snippets

Ocasionally, the prompts above might need some steering or recalibration. here are some snippets you can give right at the kick-off of each step, or look for the initial result and then copy and paste any of these.

#### [1] elite-coach-planner.prompt.md

**Steering snippets:**

> `Before finalizing the plan, flag any topic that feels redundant given the time budget and let me decide. I'd rather cut scope deeply than spread too thin. If a framework overlaps significantly with another (e.g. AutoGen vs CrewAI), call it out.`

> `Write all plan artifacts to the `artifacts/` folder as markdown. At the end, create or update `me/common-params.md` with all the parameters I gave you — I want a persistent reference I can point subagents to.`

> `After the plan is drafted, list any knowledge blocks or framework areas that the plan does NOT cover, so I can decide whether to add them or explicitly defer them.`

---

#### [2] elite-blog-author.prompt.md

**Steering snippets:**

> `Delegate each series to a subagent using `elite-blog-writer.prompt.md`. Do NOT pass parameters to the subagent directly — point it to `me/common-params.md` and the plan file and let it read those itself. Do NOT halt for approvals or questions — use your best judgment and come back only when the batch is done.`

> `Once I approve the plan, run all remaining series simultaneously in parallel subagents. Each subagent gets the same calibration instructions. Return to me only when every series has been fully written (all posts marked `written` in the plan file).`

> `Do not modify the writer prompt itself. Just trigger it as-is. The subagent writer should use the kick-off prompt stored in the plan file for each post — that is the authoritative brief.`

---

#### [3] elite-exercise-architect.md

**What gets created:**
- `artifacts/exercise-writer-prompt.md` — the self-contained prompt for the first progression.
- `artifacts/exercise-writer-prompt-progression2.md` — created if coverage gaps are found and you ask for a second progression.
- Delegate these `.md` files to a writer agent (or provide them as context to a new chat) to produce the actual exercise files under `showcase_projects/`.

**Steering snippets:**

> `Use a 3-phase progression: (1) isolated technical spikes on individual concepts, (2) a merged project that combines those concepts, (3) an advanced showcase with production concerns. Each phase must build cumulatively on the previous one — no standalone exercises.`

> `Scan the full blog plan at `artifacts/blog-plan.md`. If any blog series are NOT covered by the chosen project domain, flag them and I'll decide whether to create a complementary second progression. Organize output into subfolders per progression in `showcase_projects/`. Write the second progression's exercise-writer prompt as `artifacts/exercise-writer-prompt-progression2.md`.`

> `Prefer local/Docker-based dependencies for all exercises — no cloud services unless I explicitly request them. Propose the project domain yourself based on my industry context and the blog series; make it concrete (tied to a real product or business scenario). Don't start by asking me for a domain.`
